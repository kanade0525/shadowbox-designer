# シャドーボックス設計図メーカー

カードやイラストの画像から、シャドーボックス（重ね切り絵）の層ごとの切り出しガイドと、3D の完成イメージを作るブラウザアプリです。

**公開ページ：** https://kanade0525.github.io/shadowbox-designer/

## できること

- 画像を自動でパーツに分解し、タップで「この部分は2枚目」「ここは3枚目」と層に振り分け
- 囲み選択・ブラシ・輪郭吸着（OpenCV.js の GrabCut、未読込時は簡易モードに自動フォールバック）での細かい調整
- 層ごとの切り出しガイドを表示・画像で保存
- **A4に面付けした印刷用PDFをダウンロード**（4層ならA4を4等分、6層なら6等分。トンボ付き・原寸確認用の50mm目盛り付き）
- 層の間隔を変えながら 3D で完成イメージを確認
- **ドット絵モード**：拡大保存されたドット絵を自動で検出し、1ドット単位で編集。切り取り線もドットの角を残した階段状になります
- リロードしても作業が残る（画像と層の情報をブラウザ内に自動保存）

## 使い方

公開ページを開いて画像を選ぶだけです。手元で動かす場合は、クローンして `index.html` をブラウザで開くか、簡易サーバーを立ててください。

```
git clone https://github.com/kanade0525/shadowbox-designer.git
cd shadowbox-designer
python3 -m http.server 8000   # → http://localhost:8000
```

## ドット絵モード

ドット絵（拡大して保存されたピクセルアート）を読み込むと、自動で検出してこのモードに入ります。

- 色の変わる位置が等間隔の格子に乗っているか、各マスの中の色が一様かの2点で判定します。写真やイラストでは入りません
- ブラシが1ドット単位になります（1〜8ドット四方）。囲んで選んだ範囲もドットの境目にそろいます
- 切り取り線はドットの角をそのまま残した階段状になります（通常は角を丸めています）
- 「なめらかさ」は「何ドットぶんの出っぱり・へこみをならすか」に変わります。0なら完全にドットどおり
- 表示・ガイド・PDFのすべてで画像をにじませずに描きます
- チェックを外すと普通の画像として扱い直します。決めた層の範囲は引き継がれます

## 印刷について

「切り出しガイド」タブの「A4に面付けして印刷する」から PDF を書き出せます。層の数だけ同じ絵を1枚のA4に並べ、各マスにその層の切り取り線を赤で重ねたものです。

- 面付けは層の数に合わせて自動で決まります（4層→2×2、6層→2×3 など）。用紙の向き・1枚あたりの面数・仕上がりの幅は手動でも指定できます
- 各マスの四隅にトンボが入るので、切り離したあと重ねると層がそろいます
- 切り取り線はベクターで書き出すため、拡大しても輪郭がぼけません
- 印刷は「実際のサイズ／100%」で。ページ下の目盛りがちょうど50mmなら原寸です

## 画像の扱いと保存先

選んだ画像はブラウザの中だけで処理され、サーバーには送信されません。アップロード先もログもありません。

作業中の画像と層の情報は、同じブラウザの IndexedDB（`shadowbox-session`）に自動保存されます。リロードやタブを閉じたあとに開き直すと、続きから再開できます。保存先はその端末のブラウザの中だけで、外部には送られません。消したいときは、復元時に出るお知らせの「最初から」を押してください。

## 構成

単一の `index.html`（ビルド不要）。外部から読み込むのは以下だけです。

| 読み込み先 | 用途 |
| --- | --- |
| cdnjs.cloudflare.com | three.js r128（3D プレビュー） |
| cdn.jsdelivr.net | OpenCV.js 4.12（輪郭吸着・任意） |
| fonts.googleapis.com / fonts.gstatic.com | Dela Gothic One, Zen Kaku Gothic New |
